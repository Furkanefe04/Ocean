+--------------------+----------------+------------------+---------------------+

6. AKIŞ KONTROL YAPILARI (CONTROL FLOW)
--------------------------------------------------------------------------------
// 1. if - else if - else
if (sayi > 100) {
    OceanOutput("Çok büyük");
} else if (sayi > 50) {
    OceanOutput("Orta");
} else {
    OceanOutput("Küçük");
}

// 2. Gelişmiş For Döngüsü (from ... to ... with increasing/decreasing)
// KURAL: 'to' sınırı HARİÇTİR (EXCLUSIVE). 'i from 1 to 10' döngüsü i < 10 iken çalışır (1..9).
for (int k from 1 to 10 with increasing 1) {
    OceanOutput($"Artan K: {k}"); // 1'den 9'a kadar yazar
}

for (variable j from 100 to 0 with decreasing 10) {
    OceanOutput($"Azalan J: {j}"); // 100'den 10'a kadar yazar (0 hariç)
}

// 3. For-In (Foreach) Döngüsü
for (String oge in liste) {
    OceanOutput($"Öğe: {oge}");
}

// 4. While ve Do-While Döngüleri
while (sayac > 0) {
    sayac--;
}

do {
    sayac++;
} while (sayac < 10);

// 5. Atlama İfadeleri (stop = break, skip = continue)
while (true) {
    if (sayac == 5) {
        skip; // döngü adımını atlar (continue)
    }
    if (sayac > 20) {
        stop; // döngüyü sonlandırır (break)
    }
    sayac++;
}

// 6. Etiketli Döngüler (Labeled Loops)
anaDongu: for (int a from 1 to 5 with increasing 1) {
    icDongu: for (int b from 1 to 5 with increasing 1) {
        if (a * b == 6) {
            stop anaDongu; // Dış döngüyü tamamen kırar
        }
        if (b == 2) {
            skip icDongu;  // İç döngünün bir sonraki adımına geçer
        }
    }
}

8. SINIFLAR, KURUCULAR VE DATA CLASS'LAR
--------------------------------------------------------------------------------
Ocean'da sınıflar standart nesne yönelimli model ile tanımlanır.

Metot ve Kurucu Sözdizimi:
+------------------------------------+------------------------------------------+
| Sözdizimi                          | Anlamı                                   |
+------------------------------------+------------------------------------------+
| public function SinifAdi(...)      | Kurucu Metot (Constructor - dönüş tipi yok)|
| public void function metotAdi(...) | Void dönüşlü metot                       |
| public String function metotAdi()  | Tip dönüşlü metot                        |
| public static int function topla() | Statik metot                             |
| public sync void function guncelle()| Senkronize (monitor lock) metot          |
| public async String function oku() | Asenkron metot (CompletableFuture döner) |
+------------------------------------+------------------------------------------+

// 1. Standart Sınıf, Kapsülleme ve Kalıtım
public class Kisi {
    private String isim;
    protected int yas;

    // Kurucu Metot (Constructor: Sınıf adıyla aynıdır, dönüş tipi yazılmaz)
    public function Kisi(String pIsim, int pYas) {
        this.isim = pIsim;
        this.yas = pYas;
    }

    // Kurucu Zincirleme (this çağrısı)
    public function Kisi(String pIsim) {
        this(pIsim, 0);
    }

    public String function getIsim() { return this.isim; }
    public int function getYas() { return this.yas; }
}

// 2. Alt Sınıf (Subclass) ve Üst Kurucu Çağrısı (super)
// NOT: Normal sınıflarda primary constructor (sınıf adının yanında parantez) KULLANILMAZ.
// Constructor gövdesinde super(...) çağrısı yapılır:
public class Calisan extends Kisi {
    private double maas;

    public function Calisan(String name, int age, double maas) {
        super(name, age);
        this.maas = maas;
    }

    public double function getMaas() {
        return this.maas;
    }
}

// 3. Nesne Oluşturma (Object Instantiation: new)
Kisi k = new Kisi("Furkan", 25);
Calisan c = new Calisan("Ahmet", 30, 75000.0);

// 4. Data Class (Veri Taşıyıcı Sınıf)
// Primary constructor sözdizimi YALNIZCA 'data class' yapılarına özgüdür.
// Derleyici otomatik olarak getter, setter, equals, hashCode, toString ve copy() üretir:
public data class Urun(int id, String baslik, double fiyat);

// Data Class Kullanımı:
Urun u1 = new Urun(101, "Laptop", 45000.0);
Urun u2 = u1.copy(fiyat = 42000.0); // İmmutable kopyalama
OceanOutput(u1.toString());         // Urun(id=101, baslik=Laptop, fiyat=45000.0)

// 5. Mühürlü Sınıflar (Sealed Classes & Restricts)
// Alt sınıf izinleri 'restricts' listesiyle kesin olarak sınırlandırılır:
public sealed class Sekil restricts Daire, Dikdortgen {
    public abstract double function alanHesapla();
}

public non-sealed class Daire extends Sekil {
    private double r;
    public function Daire(double yaricap) {
        this.r = yaricap;
    }
    @Override
    public double function alanHesapla() {
        return 3.14159 * this.r * this.r;
    }
}

public final class Dikdortgen extends Sekil {
    private double genislik;
    private double yukseklik;
    public function Dikdortgen(double a, double b) {
        this.genislik = a;
        this.yukseklik = b;
    }
    @Override
    public double function alanHesapla() {
        return this.genislik * this.yukseklik;
    }
}

10. İLERİ DÜZEY GENERICS, VARYANS (+T, -T) VE SINIRLAR (<:, >:)
--------------------------------------------------------------------------------
Ocean, JVM üzerinde tam Generic Signature üreten güçlü bir generic tip sistemine sahiptir.

// 1. Standart Generic Sınıf
public class Depo<T> {
    private T icerik;
    public function Depo(T veri) { this.icerik = veri; }
    public T function al() { return this.icerik; }
}

// 2. Üst Sınır (Upper Bound <: veya extends)
public class SayisalKutu<T <: Number> {
    public double function doubleDeger(T val) {
        return val.doubleValue();
    }
}

// 3. Alt Sınır (Lower Bound >:)
// T tipi Integer veya Integer'ın üst sınıflarından (Number, Object) biri olabilir:
public class AltSinirDeposu<T >: Integer> {
    private T deger;
    public function AltSinirDeposu(T d) { this.deger = d; }
    public T function getDeger() { return this.deger; }
}

// 4. Kovaryans (+T / Üretici / Out / Covariant)
// SADECE dönüş pozisyonlarında (return type) yer alabilir.
// NOT: Kurucu metot (<init>) parametreleri nesne ilk değerleme bağlamı olduğu için
// kovaryans kontrolünden muaftır:
public class Uretici<+T> {
    private T oge;
    public function Uretici(T pOge) { this.oge = pOge; } // Kurucu parametresi geçerli
    public T function uret() { return this.oge; }        // Dönüş pozisyonu geçerli
    // public void function tuket(T x); // DERLEME HATASI: +T metot parametresinde kullanılamaz!
}

// 5. Kontravaryans (-T / Tüketici / In / Contravariant)
// SADECE metot parametre pozisyonlarında yer alabilir:
public class Tuketici<-T> {
    public void function tuket(T oge) {
        OceanOutput($"Tüketildi: {oge}");
    }
    // public T function uret(); // DERLEME HATASI: -T dönüş tipinde kullanılamaz!
}

// 6. Çift Yönlü Varyans Boru Hattı (-Giris, +Cikis)
public class DonusturucuBoru<-InType, +OutType <: CharSequence> {
    private OutType sabitCikis;
    public function DonusturucuBoru(OutType cikis) {
        this.sabitCikis = cikis;
    }
    public OutType function calistir(InType girdi) {
        return this.sabitCikis;
    }
}

11. GENİŞLETME METOTLARI (EXTENSION METHODS)
--------------------------------------------------------------------------------
Var olan sınıflara veya ilkel tiplere, kaynak kodlarını değiştirmeden dışarıdan
metot eklemeyi sağlar.
Kurallar:
- Çağrıldığı nesne 'this' anahtar kelimesi ile temsil edilir.
- Statik olarak çözümlenir (static dispatch).
- Private alanlara doğrudan erişemez, public üyelere erişir.

public class MetotGenisletmeleri {
    // String sınıfına .selamla() metodu ekleme
    public String String.function selamla() {
        return $"Merhaba, {this}!";
    }

    // int ilkel tipine .kare() metodu ekleme
    public int int.function kare() {
        return this * this;
    }
}

// Kullanım:
// "Ocean".selamla();  -> "Merhaba, Ocean!"
// 5.kare();           -> 25

14. İSTİSNA YÖNETİMİ VE KAYNAK YÖNETİMİ (`trying`)

public class IstisnaRehberi {
    public static void function test() {
        // 1. trying - catch - finally (Çoklu Catch Desteği: Type1 | Type2)
        trying {
            if (true) throw new IllegalArgumentException("Hatalı parametre");
        } catch (IllegalArgumentException | NullPointerException e) {
            OceanOutput($"Yakalama: {e.getMessage()}");
        } finally {
            OceanOutput("Kaynak temizliği.");
        }

        // 2. Try-With-Resources (Otomatik Kaynak Kapatma)
        trying (FileInputStream fis = new FileInputStream("dosya.txt")) {
            fis.read();
        } catch (IOException e) {
            OceanOutput("G/Ç Hatası");
        }
    }
}

16. ASENKRON PROGRAMLAMA VE SANAL THREAD'LER (ASYNC / AWAIT / TASK)
--------------------------------------------------------------------------------
Ocean, Java Project Loom Sanal Thread'leri (Virtual Threads) üzerinde çalışan
yerel asenkron programlama desteği sunar.

Kurallar:
- 'async' olarak tanımlanan her metot, JVM seviyesinde otomatik olarak
  'java.util.concurrent.CompletableFuture<T>' döndürür.
- 'await' ifadesi yalnızca 'async' fonksiyonlar içerisinde kullanılabilir.
- 'Task' yardımcı sınıfı (`ocean.stdlib.Task`) Project Loom sanal thread'lerini
  yönetir: Task.sleep, Task.all, Task.race, Task.isVirtual.

import java.util.concurrent.CompletableFuture;
import ocean.stdlib.Task;

public class AsenkronRehberi {
    // 1. Asenkron Metot (CompletableFuture<String> üretir)
    public static async String function uzakVeriCek(String endpoint) {
        Task.sleep(100); // Sanal thread üzerinde bloklamayan bekleme
        return $"VERI_{endpoint}";
    }

    // 2. Asenkron Akış ve Await
    public static async void function akisiCalistir() {
        CompletableFuture<String> f1 = uzakVeriCek("users");
        CompletableFuture<String> f2 = uzakVeriCek("orders");

        // Birden fazla asenkron görevi paralel bekleme:
        await Task.all(f1, f2);

        String u = await f1;
        String o = await f2;
        OceanOutput($"Sonuç: {u}, {o}");
    }
}

17. JAVA İLE DOĞRUDAN BİRLİKTE ÇALIŞMA (JAVA INTEROPERABILITY)
--------------------------------------------------------------------------------
Ocean, JVM üzerinde çalıştığından tüm Java standart kütüphanesi ve üçüncü parti
Java kütüphaneleriyle sıfır maliyetle doğrudan çalışır:

import java.util.ArrayList;
import java.util.HashMap;
import java.io.File;

class JavaInteropOrnegi {
    main() {
        // Java sınıflarını doğrudan kullanma
        ArrayList<String> javaListesi = new ArrayList<String>();
        javaListesi.add("Ocean");
        javaListesi.add("Java 21");

        for (String oge in javaListesi) {
            OceanOutput($"Java Listesi Öğesi: {oge}");
        }

        // Java Dosya API'si
        File dosya = new File("build.gradle");
        OceanOutput($"Dosya Mevcut mu: {dosya.exists()} (Boyut: {dosya.length()} bayt)");
    }
}

18. PROGRAM GİRİŞ NOKTASI (`main` METODU)
--------------------------------------------------------------------------------
Ocean'da ana metot farklı esnekliklerde tanımlanabilir. Derleyici arka planda
her durumda standart JVM `public static void main(String[] args)` metodunu üretir.

ÖNEMLİ KURAL:
'main' metodu asenkron (async) olamaz. 'main' içinde async metotlar çağrıldığında,
JVM'in görevler bitmeden sonlanmasını önlemek için döndürülen CompletableFuture
üzerinde '.join()' çağrılmalıdır.

class Program {
    // 1. En Sade ve İdiyomatik Giriş Noktası (Önerilen)
    main() {
        OceanOutput("Ocean Programı Başlatıldı!");
    }

    // 2. Asenkron İşlem Bekleyen Main Örneği (.join kuralı)
    /*
    main() {
        AsenkronRehberi.akisiCalistir().join(); // Görevler bitene kadar bekler
    }
    */

    // 3. Komut Satırı Argümanlı Main
    /*
    main(String[] args) {
        for (String arg in args) {
            OceanOutput($"Argüman: {arg}");
        }
    }
    */

    // 4. Açıkça 'static' Bildirilen Main
    /*

        OceanOutput("Statik main");

    */
}
