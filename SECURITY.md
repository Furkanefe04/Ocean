# Security Policy

## Supported Versions

Security updates are actively provided for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The Ocean team takes security seriously. If you discover a security vulnerability in the Ocean compiler, standard library, or runtime:

1. **Do not disclose the issue publicly** in an open GitHub issue or public forum.
2. Report the vulnerability privately via **GitHub Private Vulnerability Reporting** on the repository page (under the **Security** tab).
3. Alternatively, contact the maintainers directly via email.

Please include:
- A clear description of the vulnerability and potential impact.
- Minimal reproducible `.ocean` or Java code demonstrating the behavior.
- Details regarding your environment (OS, JDK version, Ocean compiler version).

We will acknowledge receipt within 48 hours and work with you on a coordinated fix and release.
